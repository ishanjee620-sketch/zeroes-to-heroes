## Task Description
In this task, I wrote a simple JavaScript program to check whether a given number is even or odd.  
The program converts a string number into an integer and then applies a condition to find the result.

## What I Did
- Stored a number as a string variable  
- Converted the string into an integer using `parseInt()`  
- Used the modulo operator (%) to check if the number is divisible by 2  
- Printed the result in the console as Even or Odd  

## Code Logic
If the number divided by 2 gives remainder 0, it is Even.  
Otherwise, it is Odd.

## Output
The program prints:
- "Even" if the number is even  
- "Odd" if the number is odd
